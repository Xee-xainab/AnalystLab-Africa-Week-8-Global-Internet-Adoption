# 🌍 Global Internet Adoption and the Gender Digital Divide: A World Development Indicators (WDI) Analysis

## 📌 Project Overview

This project was completed as the **Final Capstone Project** for the **AnalystLab Africa Data Analytics Internship (Batch B, June–August 2026)**.

The project analyzes global internet adoption using the **World Bank World Development Indicators (WDI)** dataset to examine internet usage trends across countries, regions, income groups, and gender. The objective is to identify digital inclusion patterns, evaluate regional disparities, and assess the global gender digital divide through interactive data visualization.

The analysis was developed using **Microsoft Power BI**, transforming raw development data into an interactive dashboard that supports evidence-based decision-making.

---

# 🎯 Project Objectives

The objectives of this project were to:

- Analyze global internet adoption trends over time.
- Compare internet usage across countries and regions.
- Evaluate internet adoption across different income groups.
- Examine gender disparities in internet usage.
- Identify countries with the highest and lowest internet adoption.
- Develop an interactive Power BI dashboard to communicate insights effectively.
- Provide recommendations to improve digital inclusion globally.

The dataset includes indicators on:

For this project, internet adoption indicators were selected for analysis.

# 📊 Key Findings

- 245 countries and territories were analyzed.
- Average global internet usage is **43.4%**.
- Internet adoption has increased steadily between 1990 and 2025.
- North America records the highest regional internet usage.
- Sub-Saharan Africa has the lowest regional internet adoption.
- Kosovo recorded the highest average internet usage among analyzed countries.
- Niger, South Sudan, and Chad recorded some of the lowest internet adoption rates.
- Average male internet usage (69.0%) is slightly higher than female internet usage (65.6%).
- The global average gender gap is approximately **3.7%**.
- South Asia and Sub-Saharan Africa exhibit the largest gender disparities in internet access.

---

# 💡 Key Insights

- Global internet adoption continues to improve but remains uneven across regions.
- Income level is strongly associated with internet accessibility.
- Developed regions generally experience higher digital inclusion.
- Significant digital inequality persists in lower-income countries.
- Gender disparities remain evident despite improvements in global connectivity.
- Expanding affordable internet access remains essential for sustainable development.

---

# 📌 Recommendations

Based on the analysis, the following recommendations are proposed:

- Expand broadband infrastructure in underserved regions.
- Improve affordability of internet services.
- Increase investment in digital literacy programs.
- Promote policies supporting equal digital access for women and girls.
- Strengthen public-private partnerships to improve digital connectivity.
- Prioritize investments in low-income countries.
- Monitor internet adoption indicators regularly to support evidence-based policy decisions.
